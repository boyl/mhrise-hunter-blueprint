# Hunter Blueprint 1.1.3 · 猎人蓝图

**使用前建议备份存档。Back up your save before use.**

修复部分 REFramework 环境缺少 `thread.get_hook_storage()` 时，整个外观服务被禁用的问题。现在保留幻化与染色复制，仅隐藏不可用的武器显示状态选项并提示更新 REFramework。强制请求会在准备阶段被拒绝；其他初始化异常继续明确报错。

兼容修复已通过三种 Lua 调试环境的完整离线回归及语法检查。反馈用户的接口缺失环境尚未实测；不宣称已验证所有 REFramework 构建。跨角色外观蓝图库尚未加入本版。

Fixes appearance initialization being entirely disabled when `thread.get_hook_storage()` is unavailable. Layered armor and dye copying remain available; weapon visibility synchronization is unavailable with an explanatory message. Unsupported visibility requests are rejected during preparation. Other initialization errors remain explicit.

Full offline regression passed in three Lua debug configurations, plus syntax checks. The reporting user's missing-API runtime has not been tested in-game. Cross-character appearance blueprints are not included.

## 安装 / Installation

前置：[REFramework 官方下载](https://github.com/praydog/REFramework/releases)。在 Steam 中浏览本地文件找到游戏根目录；退出游戏，将 ZIP 内的 `reframework` 文件夹合并至包含 `MonsterHunterRise.exe` 的目录，覆盖本 Mod 同名文件。保留 `reframework/data/LoadoutClone` 中的数据。重启游戏，从 Script Generated UI 打开“猎人蓝图：显示面板”。

Requires [REFramework](https://github.com/praydog/REFramework/releases). Exit the game and merge the ZIP's `reframework` folder into the game root containing `MonsterHunterRise.exe`. Overwrite this mod's files and preserve `reframework/data/LoadoutClone`. Restart and open the panel through Script Generated UI.

安装目录、卸载和既有已知限制见包内 README；旧版本保留供回退。See the bundled README for layout, removal and existing limitations. Previous releases remain available for rollback.
