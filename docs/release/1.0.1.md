# Hunter Blueprint · 猎人蓝图 1.0.1

修复部分配装无法复制，以及旧武器百龙强化遗漏的问题。

- 修复武器珠子技能总量判断造成的伪歧义。
- 正确处理不足三项的基础替换技，防止将短数组交给原生固定长度复制。
- 仅允许双方大师等级开放状态相同的猎人互相复制；未开放时保留基础替换技与空两书配置，已开放时校验完整朱／苍书。
- 补齐旧武器百龙强化；未装备护石时保留空槽。
- 加强技能、数组和写入回读校验；修复预留槽被外部改变时可能用旧备份覆盖新数据的问题。

需要 REFramework。退出游戏后，将 ZIP 中的 `reframework` 文件夹合并到游戏根目录，覆盖本 Mod 文件；保留已有配置与事务恢复记录。使用前建议备份存档。

外观复制不在此版。完整前置下载、安装和卸载说明见 [README](https://github.com/boyl/mhrise-hunter-blueprint#readme)。

---

Fixes loadouts rejected by decoration or Switch Skill validation, and missing Ramp-Up skills on older weapons.

- Removes false weapon-decoration ambiguity by checking the complete skill total.
- Normalizes short legacy Switch Skill lists before native copying.
- Requires both hunters to have the same Master Rank unlock state. Pre-MR hunters retain legacy skills with empty scroll configurations; MR hunters require complete red and blue scrolls.
- Preserves Ramp-Up skills and an unequipped talisman slot.
- Strengthens data and readback checks. Rollback no longer overwrites an externally changed slot that this transaction never modified.

Requires REFramework. Exit the game and merge the ZIP's `reframework` folder into the game directory, replacing this mod's files. Keep existing configuration and transaction records. Back up your save before use.

Layered armor copying is not included. See the [README](https://github.com/boyl/mhrise-hunter-blueprint#readme) for installation and removal.
