# Hunter Blueprint 1.1.1 · 花链修复

> **使用前建议备份存档。**

- 复制时优先复用已有同款花链，避免反复新增和误报花链箱已满。
- 新增“清理与整理花链”，处理历史重复项和清理后的空位；支持没有重复项、仅有空位的情况。
- 整理同步当前佩戴、已保存配装及武器显示绑定；只修改花链槽，不连带重算其他装备索引。
- 清理需先完成回滚验证，再手动确认；未确认不保留清理结果。
- 修复事务记录写入失败时的处理，恢复状态不明确时阻止重复写入。

已验证实机整理、故障回滚以及保存重启后花链排列和配装引用保留。其他复制功能保持原有行为。

升级：退出游戏后，将包内 `reframework` 文件夹合并到游戏根目录。保留 `reframework/data/LoadoutClone`。首次安装和前置说明见随包 README。

## English

**Back up your save before use.**

Reuses an owned matching petalace instead of creating duplicates. Adds explicit duplicate-petalace cleanup and gap removal, including inventories already cleaned by an earlier build. Updates equipped and saved-loadout references while preserving unrelated equipment indices. Cleanup requires a rollback validation and explicit confirmation. Transaction journal failures now stop unsafe repeated writes.

Validated in-game cleanup, injected-failure rollback, and petalace/loadout persistence after saving and restarting. To upgrade, close the game and merge the included `reframework` folder into the game directory. Keep `reframework/data/LoadoutClone`. See README for prerequisites and installation.
