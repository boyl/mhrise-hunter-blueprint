# Hunter Blueprint 1.1.0 · 猎人蓝图

新增外观复制，可随完整配装一起保存，也可单独复制幻化。

- 新增“复制外观（幻化与染色）”，自动登记外观组合并关联猎人个人组合。
- 新增“仅复制外观”：保留自己的装备、珠子和替换技，不受炼化孔位检查影响。
- 新增可选“复制武器显示状态”，切换猎人个人组合时应用，关闭则保留自己的设置。
- 保留 1.0.2 的受限 Lua 环境兼容修复；完善选项传递校验、角色识别及外观事务回滚。

仅外观模式暂不支持百龙武器专属染色，遇到会明确停止。武器显示绑定保存在 `reframework/data/LoadoutClone/appearance-visibility.json`，升级或迁移时请保留。

已完成离线回归、实机准备与故障回滚、外观及显示状态切换验证，并完成仅外观模式实际使用确认。使用前建议备份存档。

安装或升级：退出游戏，将包内 `reframework` 文件夹合并到游戏根目录；保留 `reframework/data/LoadoutClone`。需要 [REFramework](https://github.com/praydog/REFramework/releases)。

## English

Copy layered weapons and armor with armor pigments alongside a full loadout, or use the new **appearance-only** mode to keep your own equipment, decorations and Switch Skills. Optional weapon visibility copying applies when you equip the linked Hunter Loadout.

Appearance-only mode rejects enabled Rampage weapon dye because native layered loadouts do not store this equipment data. Keep `reframework/data/LoadoutClone/appearance-visibility.json` when upgrading or moving your installation. Weapon visibility requires this mod and is applied through Hunter Loadouts, not directly through layered loadouts.

Includes offline regression checks, in-game preparation and rollback checks, appearance/visibility switching and appearance-only user acceptance. Back up your save before use. Exit the game and merge the archive's `reframework` folder into the game root. Preserve the existing data folder; [REFramework](https://github.com/praydog/REFramework/releases) is required. The UI is Chinese.
