[size=5][b]1.2.1 · 外观染色修复 / Layered dye fix[/b][/size]
[color=#ff9900][b]使用前建议备份存档。Back up your save before use.[/b][/color]
修复“我的蓝图”保存外观时读取旧组合染色，导致导入后变回默认色的问题。现在读取当前实际外观着色，保留两通道 HSV、默认色标志及启用状态，兼容旧蓝图。

旧蓝图已经丢失的颜色无法自动恢复：更新后请在来源角色重新保存，再导入。 本次修复针对幻化／外观着色，不新增普通防具着色复制。防具显示／隐藏设置仍由当前角色保留，游戏可能因此重算染色启用标志。

实机通过完整及仅外观导入、同角色换装、同性交叉角色仅外观应用，以及保留外观组合的保存重启回读。三种 Lua 环境回归与语法检查通过。本轮未验证异性角色；完整组合的重启关联因手动整理删除受到干扰，不计为通过。

Fixes My Blueprints saving stale layered-loadout colors instead of the current layered armor dyes, causing imported appearance to use default colors. Preserves both dye channels, HSV values and native default/enabled flags while retaining compatibility with older blueprints.

Previously lost colors cannot be recovered automatically. After updating, save a new blueprint on the source character, then import it. This fixes layered armor dyes; it does not add regular armor dye copying. Armor display/hide settings remain those of the current character and may cause the game to recalculate dye enable flags.

In-game checks passed for full and appearance-only importing, same-character equipping, same-sex cross-character appearance-only application, and retained appearance-loadout save/restart persistence. Regression passed in three Lua configurations plus syntax checks. Opposite-sex equipping was not tested in this round; full-loadout link persistence was affected by manual deletion/reorganization and is not counted as passed.

[size=5][b]1.2.0 · 我的蓝图 / My Blueprints[/b][/size]
[color=#ff9900][size=4][b]使用前建议备份存档。Back up your save before use.[/b][/size][/color]
保存当前完整配装到本地蓝图库，选择条目后导入当前角色，无需大厅。包含装备、珠子、护石、花链、替换技及炼化；可选幻化、染色与武器显示状态，也可仅导入外观。旧外观蓝图兼容。新版双栏布局、分页及自适应窗口，修复数字名称和空数组保存问题。
Save your current full loadout to a local library and import it without a lobby. Includes equipment, decorations, talisman, petalace, Switch Skills and augments, with optional appearance, dyes and weapon visibility or appearance-only import. Existing appearance blueprints remain compatible. Responsive two-column layout and pagination; numeric-name and empty-array fixes.

蓝图库：[b]reframework/data/LoadoutClone/appearance-blueprints.json[/b]，最多 100 条。升级及迁移时保留整个 data/LoadoutClone 文件夹。完整配装导入要求双方大师等级开放状态相同；仅外观不限。我的蓝图默认包含外观，武器显示状态默认关闭。保存不新增装备，导入不自动换装。
The library holds up to 100 entries and is shared between characters. Preserve the entire data/LoadoutClone folder when updating or moving computers. Full import requires the same Master Rank unlock state; appearance-only import does not. Saving adds no equipment; importing does not equip the result.

本机保存、完整导入、换装及保存重启回读已通过；九组选项通过原生临时重建和写入前检查，130 个性别专属外观通过映射与临时对象检查。[b]跨角色导入与异性角色实际换装尚未实机验收。[/b]
Same-character save/import/equip and save/restart checks passed. Nine option combinations passed native temporary reconstruction and pre-write checks; 130 sex-specific appearance mappings passed temporary-object checks. [b]Cross-character import and actual equipping on an opposite-sex character remain unverified in-game.[/b]

[size=5][b]Hunter Blueprint · 猎人蓝图[/b][/size]
Copy a lobby hunter's equipment, decorations, talisman, Switch Skills and optional augments into a new Hunter Loadout. Chinese interface.
一键复制大厅猎人的装备、珠子、护石、替换技及可选炼化，保存为猎人个人组合。

[size=4][b]Features / 功能[/b][/size]
[list]
[*]Creates independent weapons, armor, talismans and applicable kinsects. Reuses an owned matching petalace, creating one only when missing. You do not need to own the source equipment.
[*]Includes regular and Rampage decorations and older weapons' Ramp-Up skills. An unequipped talisman remains empty.
[*]Full equipment copying requires both hunters to have the same Master Rank unlock state. Pre-MR hunters copy legacy Switch Skills; MR hunters copy both red and blue scrolls.
[*]完整装备复制仅允许双方大师等级开放状态相同的猎人互相复制：未开放时复制基础替换技，已开放时复制朱／苍书；保留旧武器百龙强化及未装备的护石空槽。
[*]Saves to the last empty Equipment Loadout and Hunter Loadout slots. Keeps current equipment unchanged; items are not linked; optionally links a new layered loadout.
[*]Optional augment copying, with normal-rule and relaxed reconstruction modes. Both Copy augments and Allow illegal augments are enabled by default. Relaxed mode does not necessarily produce illegal results: it tries within-budget solutions first.
[*]Checks source completeness, capacity and resulting equipment. Recoverable write errors roll back; unresolved recovery blocks further writes.
[/list]
新增完整装备，无需事先持有；保存到最后的空组合槽，不覆盖已有组合。复制炼化与“允许非法炼化（不一定实际非法）”默认开启，仍检查最终效果。取消炼化后若基础孔位装不下原珠子，会停止。

[size=4][b]Appearance options / 外观选项[/b][/size]
复制外观与武器显示状态默认关闭。勾选“仅复制外观”后，只新增外观组合及不关联装备／道具的猎人个人组合，不受大师等级状态或珠子孔位限制。使用猎人个人组合才能应用可选的武器显示绑定，直接选择外观组合不触发该扩展。
Appearance and weapon visibility copying default to off. Appearance-only mode creates layered and Hunter Loadouts without linking equipment or items, and skips equipment/progression checks. Apply the Hunter Loadout to use the optional visibility binding.

[size=4][b]Upgrade / Uninstall · 升级与卸载[/b][/size]
Exit the game before replacing the entry script and modules. Keep reframework/data/LoadoutClone, its recovery records and appearance-visibility.json. The latter stores per-character weapon visibility bindings and should also be copied when moving to another computer.
To uninstall, remove only autorun/LoadoutClone.lua and autorun/LoadoutClone/. Do not remove the shared framework or a font used by other mods. Created equipment and loadouts remain in your save.
升级保留 data/LoadoutClone 的恢复记录及 appearance-visibility.json 显示绑定。卸载后已保存的装备和外观组合仍在，武器显示绑定不再自动应用。卸载只移除本 Mod 脚本，不删除已写入存档的装备。旧开发版 config.json 若明确关闭 write_enabled，仍会禁止写入；首次安装不需要该配置。

[size=4][b]Scope / 已知范围[/b][/size]
Original augment rows are not available remotely, so reconstruction targets equivalent final effects; internal rows can differ. Normal mode uses conservative rules and can reject some legitimate special augments. Ambiguous decorations or incomplete remote data are rejected. Wait for a hunter's data to finish synchronizing after an equipment change.
仅外观模式暂不支持百龙武器专属染色，来源启用时明确拒绝；整套模式可随新建武器保存。Appearance-only mode rejects enabled Rampage weapon dye, which native layered loadouts cannot store. Full-copy mode can retain it on the new weapon.
正常模式失败不代表对方装备非法；无法确认等效结果时不猜测。回滚针对可恢复的 Lua 错误，不承诺断电、强制结束或原生崩溃时恢复。

Validated: three augment modes, real commits and rollback, basic construction of 14 weapon families, talisman effective fields, both scrolls, loadout persistence and kinsect link persistence; appearance/visibility switching, appearance-only use, and transactional rollback. This is not exhaustive coverage of every weapon ID or augment combination.
