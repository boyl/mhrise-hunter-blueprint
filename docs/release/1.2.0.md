# Hunter Blueprint 1.2.0 · 猎人蓝图

**使用前建议备份存档。Back up your save before use.**

- 新增“我的蓝图”：保存当前完整配装，在蓝图库选择并导入；无需大厅，兼容旧外观蓝图。
- 支持装备、珠子、护石、花链、替换技及炼化，导入时可选外观、染色与武器显示状态，也可仅导入外观。
- 新版双栏布局、分页和自适应窗口；修复纯数字名称与空数组保存问题，增强写入失败后的事务保护。
- 保留大厅复制、花链复用及清理功能。完整配装仍要求双方大师等级开放状态相同。

本机保存、完整导入、换装、保存重启回读已通过。九组选项通过原生临时重建与写入前检查；130 个性别专属外观通过映射和临时对象回读。三种 Lua 环境回归及语法检查通过。跨角色导入与异性角色实际换装尚未实机验收。

Adds My Blueprints: save the current full loadout and import from a shared local library without a lobby. Includes equipment, decorations, talisman, petalace, Switch Skills and augments, with optional appearance, dyes and weapon visibility or appearance-only import. Existing appearance blueprints remain compatible. Adds a responsive two-column layout and pagination; fixes numeric names and empty-array persistence, and strengthens transaction protection.

Same-character save, full import, equip and save/restart checks passed in-game. Nine option combinations passed native temporary reconstruction and pre-write checks; 130 sex-specific appearance mappings passed temporary-object checks. Cross-character importing and actual equipping on a character of the opposite sex have not been validated in-game.

## 安装 / Installation

前置：[REFramework 官方下载](https://github.com/praydog/REFramework/releases)。退出游戏，将 ZIP 内 `reframework` 文件夹合并到包含 `MonsterHunterRise.exe` 的游戏根目录。覆盖本 Mod 同名文件，**保留 `reframework/data/LoadoutClone`**，其中包含蓝图库及显示绑定。重启后从 Script Generated UI 打开“猎人蓝图：显示面板”。

Requires [REFramework](https://github.com/praydog/REFramework/releases). Exit the game, merge the archive's `reframework` folder into the game root, overwrite this mod's files and preserve `reframework/data/LoadoutClone`. Open the panel through Script Generated UI. See the bundled README for installation layout, limitations and removal.
