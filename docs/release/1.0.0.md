# Hunter Blueprint · 猎人蓝图 1.0.0

首个版本：大厅选人、一键新增装备并登记猎人个人组合。

- 武器、五件防具、护石、花链、猎虫、普通珠及百龙珠。
- 朱／苍书替换技；可选炼化，放宽模式优先预算内还原。
- 保留当前穿着，缺省道具与外观关联，不覆盖已有组合。
- 完整数据、容量与效果校验；异常回滚与恢复失败锁定。
- 中文面板支持左对齐列表、收起、关闭和随 REFramework 隐藏。

安装：退出游戏，把 ZIP 内的 reframework 文件夹合并到游戏根目录。需要单独安装 REFramework；中文字体已附带。

实机验证三种炼化模式的成功入库与故障回滚、14 类武器基础构造、护石有效字段、组合重启保留与猎虫关联保存。容量等破坏性边界采用自动模拟验证，未人为塞满真实存档。

外观复制不在此版。正常规则求解保守，无法确认的配装会拒绝；不承诺所有武器 ID、炼化组合、其他平台或原生崩溃恢复。

完整安装、升级与卸载说明见 README.md。
