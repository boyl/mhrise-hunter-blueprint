# Hunter Blueprint · 猎人蓝图 1.0.2

修复部分运行环境中面板只有标题和按钮、正文空白的问题。

- 不再强制依赖 Lua debug 库；缺少 debug 或 traceback 时仍能刷新大厅、绘制面板与处理复制错误。
- 保留协程实际错误信息，确保事务失败仍能执行恢复逻辑。
- 补齐窗口正文的异常保护，以默认字体显示可读的错误提示，避免重复刷日志。

本版不改变装备复制规则、配置和存档格式，不包含外观复制。

退出游戏，将压缩包内 reframework 文件夹合并到游戏根目录，覆盖本 Mod 文件；保留已有配置及事务恢复记录。使用前建议备份存档。完整安装说明见 README。

---

Fixes a blank panel in environments where Lua's debug library is unavailable.

- Lobby refresh, panel rendering and copy error handling no longer require debug.traceback.
- Coroutine failures retain their actual error messages; transaction rollback remains available.
- Panel errors now show a readable diagnostic message using the default font, with duplicate logging suppressed.

No changes to equipment-copy rules, configuration or save formats. Appearance copying is not included.

Requires REFramework. Exit the game, then merge the archive's reframework folder into the game directory. Replace this mod's files and retain configuration and transaction records. Back up your save before use. See README for full installation instructions.
